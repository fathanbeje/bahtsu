## 🏷️ Konvensi Penamaan Berkas
Setiap berkas disimpan dengan format:
```
kajian/YYYY-MM-DD-slug-tema.md
```
Contoh:
- `kajian/2026-09-25-status-hukum-cryptocurrency.md`
- `kajian/2026-09-25-tinjauan-fikih-sound-horeg.md`
- `kajian/2026-09-25-status-qadha-shalat-mayit.md`
